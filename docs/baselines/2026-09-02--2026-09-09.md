## Verified Landed Result

Status: **not yet computed**.

The collection verified the raw objective cohort and linkage count. It did not
apply the complete landing, current-Check, original-chain, and rescue-chain
evidence rules in the [production metric contract](../production-metrics.md).
Therefore this baseline does
not publish a verified landed numerator or rate.

The first production metric implementation must calculate the result from the
same fixed cohort and must preserve this raw count. It must report a reason for
each of the four leaf slices with no voyage link and for every other slice that
does not have complete evidence.

## Grouping Coverage

Across all 983 objectives at capture time:

- 173 objectives have a `port:<family>` tag.
- 203 objectives have no `Category`.
- `Kind` is present on the objective records.

The metric surface must use `port:<family>` for source family. It must use
`Category` and `Kind` as separate work-type fields. Missing source family or
category must remain `unknown`; title text is not a replacement.

These inventory counts describe all current objectives. The first metric run
must also publish tag and category coverage for the 127-slice cohort.

## Query Coverage and Limits

The collection used `list_objectives` and paginated `armada_enumerate` calls.
It did not request Check command output or unrelated event payloads. The
objective list returned at most 500 objects per page even when a larger page
size was requested.

The raw cohort scan followed all objective pages and used all 983 current
objective rows to find child links. This is necessary because a child can be
outside the completion window.

The record inventory followed all reported pages for each named entity. A
future API response must state its own scan limit, scanned count, total count,
and truncation state so a bounded scan cannot appear complete when it is not.

## Concurrency Decision

Dispatch and Check concurrency remain unchanged.

The main verified measure is not available, Check queue history has an
unproven semantic cutover, and idle lane-minutes are not recorded. The current
data cannot prove that more concurrency is safe or that capacity is the main
constraint. Record at least one comparable verified baseline before a
concurrency change.
