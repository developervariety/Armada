IDs are generated by Constants.IdGenerator (PrettyId.IdGenerator) with GenerateKSortable(prefix, 24), so they sort by creation time. Prefix constants live in src/Armada.Core/Constants.cs (a few are inline in model classes).

Core: flt_ Fleet, vsl_ Vessel, cpt_ Captain, msn_ Mission, vyg_ Voyage, dck_ Dock, sig_ Signal, evt_ ArmadaEvent, mrg_ MergeEntry, art_ AgentRuntime.
Pipelines/config: prs_ Persona, ppl_ Pipeline, pps_ PipelineStage, ptpl_ PromptTemplate, pbk_ Playbook (Runbook reuses its playbook id), skl_ Skill, wfp_ WorkflowProfile, ppf_ ProjectProfile, mep_ ModelEndpoint, mem_ Memory.
Planning/backlog: obj_ Objective (backlog item), ors_ ObjectiveRefinementSession, orm_ ObjectiveRefinementMessage, psn_ PlanningSession, psm_ PlanningSessionMessage.
Delivery: chk_ CheckRun, rel_ Release, dpl_ Deployment, env_ DeploymentEnvironment, dvd_ DeploymentVerificationDefinition, inc_ Incident, rbx_ RunbookExecution, rbs_ RunbookStep.
Auth: ten_ Tenant, usr_ User, crd_ Credential (synthetic ids ten_system / usr_system back the local API key).
Ask Armada: ath_ AskThread, amg_ AskMessage, atc_ AskMessageToolCall, aap_ AskActionProposal, atw_ AskTrackedWork.
Ops: job_ Job, hbr_ Harbor, req_ RequestHistory, tku_ TokenUsageRecord, rbd_ server rebuild, fac_ FleetAction, far_ FleetActionRun, fat_ FleetActionRunTarget, vhl_ VesselHealth, vhf_ VesselHealthFinding, vdp_ VesselDependency, vho_ VesselHealthOverride, vib_ VesselImportBatch, vii_ VesselImportItem, vfr_ VesselImportFleetRecommendation.
Non-entity: mission branches use prefix "armada/" (Constants.BranchPrefix); merge-queue temp worktrees are named mq_<entryId>_<timestamp>.
