parity.json ("Dashboard-to-TUI parity manifest"; generated by scripts/tui/generate-parity-manifest.py, statuses maintained by hand) has statuses implemented, planned, not-applicable (with a reason), extension; each entry has kind (route, tab, api, event, setting), key, status, tui (screen or command, e.g. HomeScreen, HubScreen, Router for redirects, ArmadaClient.Method), workstream, notes. Counts as of 2026-10-05: 84 routes, 39 tabs, 320 api, 28 events, 55 settings; 521 implemented, 5 extension (/approvals ApprovalsScreen, /setup SetupWizardScreen, tui:GetI18nCatalogAsync, tui:GetOpenApiDocumentAsync, tui:SendRawAsync), 0 planned. It is embedded in the Armada.Tui assembly. The Tui.Parity suite enforces it (see tui-parity-generator-and-suite). Parity means every dashboard screen, tab, table, filter, row action, bulk action, form field, modal, live update, and setting has a terminal equivalent; the TUI is a thin client and adds no server endpoints of its own except where TUI_APP_PLAN.md lists server changes.
