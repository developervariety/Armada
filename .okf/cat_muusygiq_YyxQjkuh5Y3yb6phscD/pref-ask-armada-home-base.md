The owner wanted Ask Armada to become a conversational home base with threads where you can kick off actions and monitor progress end to end. His choices: state-changing actions appear as a Confirm card (proposal) the user approves; a captain answers plus slash quick actions; full lifecycle tracking of started work; threads are private per user. The Ask prompt should keep context about the specific vessels discussed, know global state ("what's running"), and stay a simple prompt adjustment rather than heavy machinery. Captain auto-approve for Ask turns is off by default (security). See docs/ASK_ARMADA_HOME_BASE.md.
