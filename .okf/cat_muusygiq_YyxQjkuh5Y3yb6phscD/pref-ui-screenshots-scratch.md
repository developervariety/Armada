When changing a UI (Harbor, dashboard, mobile), capture screenshots in light and dark mode into a scratch folder outside the repo, critique them, and tell the owner where they are. Open the folder in Finder when the owner asks to see them.

Why: on 2026-10-08 the owner said they love this practice but asked that screenshots never be committed; they take the repo and README screenshots themselves.

How to apply: never add review screenshots to the repo or a commit. README TUI captures are a separate, generated asset ([[tui-readme-frames-capture]]).
