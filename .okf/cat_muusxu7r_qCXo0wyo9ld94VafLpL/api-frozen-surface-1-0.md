Policy: docs/COMPATIBILITY.md (SemVer from 1.0.0: minors/patches never break clients, scripts, or settings files of the same major).
Covered: REST methods + templates, per-route auth level (never tightened except as a security fix), request/response fields and types, ApiErrorResponse + Error codes, status codes incl. 404 cross-tenant, pagination and EnumerationResult, PascalCase; MCP tool names, argument names/types/required-ness, auth level, result fields, the {"Error": ...} convention; WebSocket /ws endpoint + auth, routes, message fields, command actions and reply envelope, event types/recipients/payload fields, camelCase; CLI command names, positional args, long options and short aliases, required-ness, exit status, --json field names; settings.json keys, types, meaning, accepted enum values. NOT covered: experimental items ([[api-experimental-surfaces]]), human-readable text (Message, descriptions, help, logs), defaults, event-log-only event types, ordering of unsorted results and timing fields, free-form Data/Metadata/JSON-text fields, internal C# APIs, DB schema, prompt/persona text, files under the data dir except settings.json, the proxy API and tunnel protocol (versioned separately), and the TUI (decision at first RC).
Compatible in a minor: new routes/tools/commands/events/CLI commands, optional fields/args/options, response fields, enum values, settings keys with behavior-preserving defaults, loosening auth, making required optional. Breaking (major only, after one minor of deprecation with CHANGELOG + [Deprecated] markers): removals/renames/type changes, tightening auth, new required inputs.
Regenerate: scripts/common/generate-api-surface.sh (Windows .bat) boots a throwaway Admiral and rewrites both files from the running code (route table + OpenAPI + RouteAuthorizationRegistry, registered MCP tools + McpToolAuthorizationRegistry, WebSocketSurface, Helm command model, ArmadaSettings reflection). E2E.ApiContract compares live vs JSON, prints BREAKING/ADDED/NOTES, checks experimental markers, command handlers, broadcast events declared, and MD == JSON. When adding anything: declare auth (registries), declare WS commands/events in WebSocketSurface, regenerate, commit in the same change; review surface diffs like code. A major release starts api-surface-2.0.json.
