Source: src/Armada.Core/Settings/ArmadaSettings.cs + nested classes (DatabaseSettings, RestSettings, McpSettings, LoginRateLimitSettings, MessageTemplateSettings, RemoteControlSettings, TelemetrySettings, HarborServerSettings, VesselImportSettings, AskSettings, FleetActionSettings, RepositoryHealthSettings (+Thresholds), RetentionSettings, AgentSettings list, EscalationRule list); setters validate/clamp. The frozen listing (docs/API_SURFACE_1.0.md "Settings") is generated by reflection over ArmadaSettings: dotted camelCase paths, [] for list element fields, types, fresh-install defaults.

REST (src/Armada.Server/Routes/StatusRoutes.cs, AdminOnly): GET /api/v1/settings -> BuildSettingsResponse, an anonymous object with AdmiralPort, McpPort, MaxCaptains, HeartbeatIntervalSeconds, StallThresholdMinutes, IdleCaptainTimeoutSeconds, PlanningSession* timeouts/retention, AutoCreatePr, DataDirectory, DatabasePath, LogDirectory, DocksDirectory, ReposDirectory, SelfVesselId, RebuildSlotRetentionCount, RemoteControl (password and enrollment token returned as "********"), Import, FleetActions, RepositoryHealth, Retention. PUT /api/v1/settings (SettingsUpdateRequest) applies changes; nested groups such as FleetActions are replaced whole; a redacted or omitted secret keeps the stored value; Import/FleetActions/RepositoryHealth/Retention apply live, ports and listener settings need a restart. The proxy blocks PUT /api/v1/settings remotely.
Selected keys and defaults: admiralPort 7890, mcpPort 7891, heartbeatIntervalSeconds 10, stallThresholdMinutes 10, maxRecoveryAttempts 3, maxMissionRuntimeMinutes 240, reviewTimeoutMinutes 1440, maxNoOpRedispatchAttempts 1, maxMissionRecoveryAttempts 2, maxLandingRetries 3, captainQuarantineMinutes 15, captainCrashLoopThreshold 3/windowMinutes 15, maxCaptains 0 (auto 5), minIdleCaptains 0, maxConcurrentMissions 0, isolateCaptainLaunch false, landingMode null, branchCleanupPolicy LocalOnly, autoPush true, rest.hostname localhost, mcp.allowUnauthenticatedLoopback true, mcp.toolCallsPerSecond 100, dataRetentionDays 30. Experimental keys: harbor.*, deploymentMode, requireHarborForLaunch, rebuildSupervisorHarborId, rebuildSlotRetentionCount, selfVesselId.
